Common mistakes

  1. Trusting a page count as proof of no loss. The same count can hide reordered, duplicated or wrong pages. This fixture compares labels and their order as well as geometry/rotation; visually inspect the real result.
  2. Reusing an old output name. This tool refuses existing destinations, even when they are an input, empty file or link. Pick a genuinely new path; do not delete old work to force practice to pass.
  3. Using page copies for signed or interactive documents. This lesson does not preserve digital signatures, forms, outlines or all document-level features. Use a suitable document workflow instead.
  4. Opening an untrusted PDF because processing is local. Local does not mean sandboxed or safe against malicious files. Practise only with these generated files.

Frequently asked questions

Does a successful merge prove nothing was lost?

No. Counts only count pages. The helper compares known extracted text labels, order, page geometry and rotation for six fictional pages, plus original hashes. It is not a visual or whole-document validator.

Does this tool overwrite an original?

Every output is opened with exclusive xb creation after serialization. Existing destinations, including an input path, hardlink or symlink, are refused. Small tests check input and refused-output bytes and modification times. Concurrent hostile changes are outside the test scope.

Does it preserve forms or digital signatures?

No such promise. This tool copies pages with add_page, not an entire document with all features. Encrypted files are rejected. Keep originals and use another workflow when those features matter.

Does local mean there is no internet use?

Installing pypdf requires downloading a dependency. The visible PDF commands have no upload or network code. The lesson cannot control cloud sync, telemetry or other software on your machine.

Why are the practice pages labeled?

Unique visible fictional labels let us inspect content and order. Blank pages and equal counts alone cannot demonstrate those properties.
